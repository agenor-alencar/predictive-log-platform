# 🧩 Componentes Técnicos e Relevância de Mercado

## ☕ API Java (Orquestração)
- **Tecnologia**: Spring Boot 3.2, Java 21.
- **Função**: Orquestra a ingestão de logs, expõe APIs REST, gerencia segurança, métricas e integração com Kafka/Redis.
- **Importância no mercado**: APIs robustas e escaláveis são essenciais para empresas que precisam processar grandes volumes de logs em tempo real. Java continua a ser a escolha dominante em backend corporativo devido à sua estabilidade, desempenho e ecossistema de microserviços.

## 🐍 Serviço ML Python (Inteligência)
- **Tecnologia**: FastAPI, Scikit‑Learn, XGBoost, MLflow.
- **Função**: Treina, serve e versiona modelos de predição de erro e tempo de resposta.
- **Importância no mercado**: A demanda por IA em tempo real cresce rapidamente. FastAPI oferece baixa latência, enquanto MLflow garante governança e rastreabilidade, requisitos críticos em setores regulados como finanças e saúde.

## 🗄️ PostgreSQL
- **Tecnologia**: PostgreSQL 16.
- **Função**: Armazena logs, predições e métricas de observabilidade.
- **Importância no mercado**: Banco de dados relacional confiável e open‑source, amplamente adotado para analytics, compliance e auditoria de dados.

## 📊 Redis Cache
- **Tecnologia**: Redis.
- **Função**: Cache de resultados de predição e dados de sessão para reduzir latência.
- **Importância no mercado**: Cache em memória é crítico para sistemas de alta taxa de requisições, melhorando desempenho e escalabilidade.

## 📈 Kafka Streams
- **Tecnologia**: Apache Kafka.
- **Função**: Processamento de eventos de logs em tempo real, permitindo pipelines de ingestão escaláveis.
- **Importância no mercado**: Streaming de dados é essencial para observabilidade, detecção de anomalias e análise em tempo real em grandes infraestruturas.

## 📦 MLflow Tracking Server
- **Tecnologia**: MLflow.
- **Função**: Registro de experimentos, versionamento de modelos e artefatos.
- **Importância no mercado**: Governança de modelos é requisito regulatório em setores como finanças, saúde e seguros, facilitando auditoria e reprodutibilidade.

## 📈 Prometheus & Grafana
- **Tecnologia**: Prometheus, Grafana.
- **Função**: Coleta métricas e visualização de dashboards operacionais.
- **Importância no mercado**: Observabilidade é mandatória para equipes de SRE e compliance, permitindo monitoramento proativo e resposta rápida a incidentes.

## 🐳 Docker Compose
- **Tecnologia**: Docker, Docker‑Compose.
- **Função**: Orquestra todos os containers, simplificando deploy e CI/CD.
- **Importância no mercado**: Facilita a implantação consistente em ambientes de nuvem e on‑premises, reduzindo tempo de entrega e erros de configuração.
